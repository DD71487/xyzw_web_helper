# 代码资源文件夹使用说明

## 文件夹概述

本文件夹包含 XYZW 游戏 Token 管理器项目的全部代码资源，按不同阶段和用途分为 5 个子文件夹。适合从未接触过本项目的新人快速上手。

---

## 文件夹结构

```
代码资源/
├── 1-网页版原始代码（minified）/     # 从网页直接抓取的压缩代码
├── 2-网页版格式化后的代码（prettier格式化）/  # 格式化后的可读代码
├── 3-APK版本原始代码/               # 从安卓安装包提取的代码
│   ├── APK528/                     # 528版本
│   └── APK529/                     # 529版本
├── 4-翻译文档/                      # 各模块功能说明文档
└── 5-开源项目代码（移植目标）/        # 可直接运行的完整开源项目
```

---

## 各文件夹详细说明

### 1. 网页版原始代码（minified）

**用途**：从网页版直接抓取的生产环境代码，经过压缩混淆。

**内容**：
- `chunks/` - 代码分片文件（55个 JS 文件）
- `js/index-UoU16364.js` - 入口文件
- `index.html` - 网页入口
- `chunk_urls.txt` / `js_urls.txt` - 资源地址记录

**适用场景**：
- 分析网页版实际运行的代码逻辑
- 对比不同版本的差异
- 逆向工程参考

**注意**：代码经过压缩，变量名被混淆，阅读困难。建议查看第 2 个文件夹的格式化版本。

---

### 2. 网页版格式化后的代码（prettier格式化）

**用途**：使用 Prettier 工具格式化后的代码，可读性较好。

**内容**：与第 1 个文件夹相同，但代码格式已美化。

**适用场景**：
- 阅读网页版代码逻辑
- 查找特定功能实现
- 对比 APK 版本的差异

**使用方法**：
```bash
# 用 VS Code 或任意编辑器打开 JS 文件即可阅读
# 推荐安装 Prettier 插件获得更好的格式化效果
```

### 3. APK版本原始代码

**用途**：从安卓 APK 安装包中提取的前端代码。

**子文件夹**：
- `APK528/` - 528 版本的代码（82 个文件）
- `APK529/` - 529 版本的代码（82 个文件）

**内容特点**：
- 包含 JS 文件和 CSS 文件
- 文件名包含哈希值（如 `BatchDailyTasks-CDlX_GQ6.js`）
- 与网页版代码结构类似，但可能有版本差异

**适用场景**：
- 对比不同 APK 版本的更新内容
- 分析移动端特有的代码逻辑
- 找回网页版已移除的功能

## 快速开始（5-开源项目代码）

### 环境要求
- Node.js 18+ 
- pnpm 10+（推荐）或 npm

### 安装步骤

```bash
# 1. 进入项目目录
cd "5-开源项目代码（移植目标）"

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm run dev

# 4. 构建生产版本
pnpm run build
```

### 访问项目
- 开发环境：http://localhost:3000
- 构建输出：`dist/` 文件夹

## 核心功能模块

### 1. TokenCard 组件
- **文件**：`src/components/TokenCard.vue`
- **功能**：展示单个游戏账号的实时数据
- **包含**：游戏数据、快捷操作按钮、展开/收起控制

### 2. 批量日常任务
- **文件**：`src/views/BatchDailyTasks.vue`
- **功能**：批量执行游戏日常任务
- **包含**：任务模板、定时任务、分组管理

### 3. Token 管理
- **文件**：`src/stores/tokenStore.ts`
- **功能**：管理游戏 Token、WebSocket 连接
- **包含**：连接管理、游戏数据缓存、自动刷新

## 常见问题

### Q1: 为什么有 5 个不同的代码文件夹？
**A**: 这是项目演进的不同阶段：
- 第 1、2 个：从网页版抓取（用于分析）
- 第 3 个：从 APK 提取（用于对比）
- 第 4 个：文档说明（用于学习）
- 第 5 个：完整开源项目（用于开发和运行）

### Q2: 应该主要看哪个文件夹？
**A**: 新手建议按以下顺序：
1. 先看 `4-翻译文档/` 了解功能
2. 再看 `5-开源项目代码（移植目标）/` 的代码
3. 需要对比时再看其他文件夹

### Q3: 如何对比不同版本的代码差异？
**A**: 使用 VS Code 的对比功能：
```
1. 选中文件 → 右键 → "选择以比较"
2. 选中另一个文件 → 右键 → "与已选项目比较"
```

### Q4: 网页版和 APK 版代码有什么区别？
**A**: 主要区别：
- 网页版：通过浏览器运行，代码在 `chunks/` 中
- APK 版：通过 WebView 运行，代码直接放在根目录
- 功能上基本一致，但可能有版本差异

## 开发注意事项

1. **主要修改 `5-开源项目代码（移植目标）/` 中的代码**

3. **不要直接修改 1-3 的原始代码**（它们只是参考）
4. **文档更新放在 `4-翻译文档/` 中**
